# Gun Creator — Tkinter

**Русский** | [English](README.en.md)

Небольшая настольная программа на Python, которая случайно генерирует вымышленные названия и характеристики оружия по выбранному типу и уровню.

## Что находится в репозитории

- Интерфейс Tkinter и генерация характеристик находятся в `Gun_Creator_tkinter/main_2.py`.
- Текстовые таблицы в `Gun_Creator_tkinter/adjective/` содержат части названий; изображения иллюстрируют типы оружия.

## Запуск и настройка

Нужен Python с Tkinter. Запустите `python Gun_Creator_tkinter/main_2.py` из корня репозитория.

## Примечания

Сгенерированные названия и значения предназначены для развлечения и не являются характеристиками реального оружия.
