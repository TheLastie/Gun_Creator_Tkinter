# Gun Creator — Tkinter

[Русский](README.ru.md) | **English**

A small Python desktop toy that randomly generates fictional weapon names and stats from a selected weapon type and level.

## Included in this repository

- Tkinter interface and random stat generation are implemented in `Gun_Creator_tkinter/main_2.py`.
- Text tables in `Gun_Creator_tkinter/adjective/` provide name fragments; image assets illustrate weapon types.

## Getting started

Requires Python with Tkinter. Run `python Gun_Creator_tkinter/main_2.py` from the repository root.

## Notes

Generated names and values are for entertainment and are not real-world weapon specifications.
